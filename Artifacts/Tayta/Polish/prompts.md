## Carrera

Use case: identity-preserve. Asset: SUYURUN Tayta RUNNING sprite sheet. Reference is exact existing Tayta character: red woven chullo, red/orange triangular poncho, brown skin, dark teal trousers, dark shoes; muscular arms for Sierra, protective green/brown woven armor and feather shoulders for Selva, NO arms at all for Costa. Generate ONE transparent sprite atlas, THREE rows of EIGHT equally spaced frames, uniform grid 8 columns x3 rows. Row1 Costa WITHOUT arms, row2 Sierra WITH arms, row3 Selva WITH armor. Same face and hat in all rows. Full body facing RIGHT lateral 2D. CRITICAL animation is a real fast RUN, not an arm-only walk: eight consecutive poses contact, compression/down, passing knee tucked, flight/up, opposite contact, opposite compression, opposite passing, opposite flight. Knees visibly bend, forward knee lifts high, trailing foot curls toward buttock, feet alternate front/back, both feet airborne in flight. Legs must have different silhouettes in all frames, smooth continuous loop. Torso consistent size, hat-to-hip proportion identical across frames, body bob only 1-2 native pixels, no shrinking. Detailed polished native 48x48-per-cell equivalent pixel art, 16-bit clean color clusters, no blur/antialias, dark 1pixel contours. No ground, no text, no shadows outside sprite, no gun. Equal uniform scale across all three rows. Reference image 1 is three costume designs; preserve costumes and identity but improve the running poses only.

## Disparo

Use case identity-preserve. Unity pixel art asset SUYURUN Tayta firing pistol. Reference 1 exact existing costume and face of Tayta: red chullo with green woven band, red poncho, brown skin, dark teal trousers. Reference 2 is running leg mechanics. Create one transparent atlas: TWO rows, EIGHT equally spaced cells per row, 16 full-body sprites. Row1 Sierra muscular arms, row2 Selva green/brown woven protective armor and shoulder feathers. Every frame exactly same character dimensions and same hand-held pistol. A single compact dark gray pistol with short straight silver barrel, brown grip pointing DOWN gripped firmly in the FRONT/right hand; NO floating gun. Right-facing lateral 2D. RUNNING WHILE FIRING: feet must cycle contact/compression/passing/flight twice, bent knees and backward heel up, no stiffness, front arm extended with pistol at chest height, elbow slight recoil; second hand supports firing wrist. Frames 0/2/4/6 modest amber muzzle flash, others recoil, body never shrinks and never disappears. Same consistent scale in every cell, face/torso/head identical size. Polished crisp native48x48 pixelart equivalent with clean 1px dark outlines and limited colors, no antialiasing, blur or soft gradients. Every cell has only ONE character, fully present, no detached limbs, no extra effects outside flash, no labels/text/grid/background or ground. Use true alpha transparent background.
